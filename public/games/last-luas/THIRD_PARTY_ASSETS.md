# Last Luas third-party assets

## Quaternius animated characters

Last Luas v0.4 uses the following character files from the public `euuuuuuan/fatal-funnel-public` snapshot at commit `29a6bdfd01ad175c389cbd0bac80c30f926ff96b`:

- `quaternius-men/casual-character.glb`
- `quaternius-men/worker.glb`

Original creator: Quaternius  
Pack: Ultimate Modular Men  
License: CC0 1.0 / public domain dedication  
Source pack: https://quaternius.com/packs/ultimatemodularcharacters.html

The files are loaded at runtime from a commit-pinned jsDelivr GitHub URL. The pinned source repository also records these files as Quaternius / Ultimate Modular Men / CC0-1.0 in its public credits.

No character model is copied into this repository in v0.4.
