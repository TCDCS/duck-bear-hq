# Site 1 Implementation Plan

> For agentic workers: execute task-by-task with superpowers:executing-plans. Preserve the baseline and run the complete regression suite before release.

**Goal:** Implement the approved Site 1 personal website continuation with real private persistence and clear sublinks.
**Architecture:** Extend the current Worker after authentication, sharing its authentication helpers. Add D1 tables for permissions, users' section records and R2 metadata. Serve the new section UI from a shared static shell while preserving games and legacy pages.
**Tech Stack:** Cloudflare Workers, D1/SQLite, R2, vanilla ES modules, CSS, Node test runner and browser Playwright.
**Spec:** docs/superpowers/specs/2026-09-29-site-1-design.md

## Global constraints

No destructive database reset; no new provider; no private media in public Git. Website version 7.0.0; leave game versions unchanged. Scrapbook remains pair-only. New users receive no implicit legacy or family access. Preserve the original public menu archives.

## Review focus

1. New accounts guessing legacy API or attachment URLs must not read the original couple's data.
2. Permission removal and disabled accounts must lose access immediately, including images.
3. Concurrent record edits must fail with a 409 rather than overwrite newer content.
4. Media supplied from the wrong section or disguised as an image must be rejected.
5. Missing migration/sender configuration must produce honest, actionable errors.
